# Example configurations

- `../../atlas/root_soil_atlas.yaml` is the complete six-preset by six-soil
  frozen atlas configuration.
- `one_root.yaml` identifies the exact condition used in tutorial 1 without
  duplicating or changing any trait or soil parameter.
- `paired_roots.yaml` identifies the shared environment block used in tutorial
  2.

These selectors do not define new mechanisms, root types or soil families.
